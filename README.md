# Deep_learning_project
Pneumonia Detection Using CNN

A Deep Learning based web application that detects Pneumonia from Chest X-ray Images using Convolutional Neural Networks (CNN) and Streamlit.

Project Overview

This project uses Artificial Intelligence and Deep Learning techniques to classify chest X-ray images into:

Normal
Pneumonia

The model is trained using CNN on a Chest X-ray dataset and predicts whether a patient is infected with Pneumonia.
Features

Chest X-ray Image Upload
AI-based Pneumonia Detection
CNN Deep Learning Model
Streamlit Web Interface
Real-time Prediction
Simple and User-Friendly UI

Technologies Used
Python
TensorFlow / Keras
CNN (Convolutional Neural Network)
NumPy

PIL (Python Imaging Library)
Dataset

Chest X-ray Pneumonia Dataset on Kaggle
